# Public structure fixtures

These are unchanged downloads, not structures generated by Protein Studio.

- **1UBQ**: experimental ubiquitin, 76 resolved C-alpha residues. [RCSB record](https://www.rcsb.org/structure/1UBQ).
- **1CRN**: experimental crambin, 46 resolved C-alpha residues. [RCSB record](https://www.rcsb.org/structure/1CRN).
- **P0CG47**: AlphaFold DB polyubiquitin-B, 229 residues, database model file v6. PDB B-factor values contain historical predicted pLDDT; the accompanying JSON contains published PAE. [AlphaFold DB record](https://alphafold.ebi.ac.uk/entry/P0CG47).

Experimental B factors are not interpreted as prediction confidence. All three examples have provenance mode `reference` and `newPrediction=false`; the AFDB example has `structureType=predicted` to distinguish its historical prediction from the experimental structures. Database file version v6 is not an AF2 executable version.

`manifest.json` records original download URLs, retrieval date, exact bytes and SHA-256 values. `P0CG47_metadata.json` preserves the API response. The parser displays one C-alpha per residue; original all-atom files remain available for download.
